# Deterministic skill evaluation: 2026-10-20

Author: Hesham Salama <hesham.salama@rub.de>.

All 24 skills passed the bundled deterministic evaluation: **115 cases,
131 executable checks and 725 assertions**. This expands the previous catalog
of 101 cases, 117 checks and 686 assertions. The expanded gate passed on Windows and Linux; the full Windows regression
suite passed 1,633 tests. The run began on October 19 and completed on October 20
(Europe/Berlin). No existing numerical tolerances
were relaxed to add these cases.

## New scenarios

| Skill | New cases | Evidence tested |
|---|---:|---|
| numerical-stability | 3 | Mixed advection/diffusion fails and passes around the combined bound; negative diffusion cannot receive a dissipative certificate. |
| convergence-study | 4 | Observed order is distinct from the extrapolated observable; diverging and oscillatory data do not support extrapolation; unequal grid ratios recover a manufactured error law. |
| ontology-mapper | 2 | BCC conflicts with space group 225 and agrees with 229 without silently changing the declared lattice. |
| md-analysis-planner | 1 | A solid does not automatically qualify for a bulk-fluid hydrodynamic correction. |
| post-processing | 2 | Five unit-density nodes integrate to one over a unit interval; a diagonal contour has Euclidean length sqrt(2). |
| simulation-validator | 1 | One energy sample is insufficient to establish monotone decay. |
| time-stepping | 1 | A minimum timestep exceeding the safety-adjusted stability limit is rejected. |

Each scenario is in the skill's `evals/evals.json`, with a user prompt, expected
interpretation, natural-language assertions and executable `script_checks`.
Small analytic input fixtures are in `evals/files/`. Expected values follow the
stated formulas or geometry; they are not fitted to a solver output.

The infeasible-timestep case checks rejection via exit code 2. The remaining
new cases check structured scientific values or evidence decisions. Broader
analytic parameter sweeps and controlled evaluator subprocess tests remain in
the regression suite; they are complementary to these 14 scenarios.

## Reproduce

```sh
python tools/run_skill_evals.py
python tools/validate_skills.py
python tools/build_index.py --check
python -m pytest tests/unit tests/integration
```

`metadata.last_deterministic_eval` and the corresponding index field record
this successful deterministic run. Historical `last_evaluated` dates remain
unchanged. `agent_evaluation_status: not_revalidated` explicitly distinguishes
these script checks from fresh live-agent evaluation.

## What this does not establish

The natural-language prompts are prepared for agent evaluation, but this run
executes their script checks directly. It does not measure skill discovery,
tool selection, unrestricted scientific prose or with-skill versus baseline
uplift. Those require fresh paired live-agent runs. Historical uplift numbers
are not current evidence for the corrected evaluator.

No external materials solver or unresolved 2D phase-field refinement campaign
is included in this evaluation. See [validation scope](../VALIDATION_SCOPE.md).
